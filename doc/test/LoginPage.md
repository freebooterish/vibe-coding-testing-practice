## [x] 【前端元素】渲染登入頁面基本元素
**範例輸入**：進入登入頁面  
**期待輸出**：頁面應正確渲染「歡迎回來」標題、Email 輸入框、密碼輸入框及「登入」按鈕

---

## [x] 【表單驗證】Email 格式錯誤時顯示錯誤訊息
**範例輸入**：在 Email 輸入框輸入 `invalid-email`，並點擊登入按鈕  
**期待輸出**：畫面顯示「請輸入有效的 Email 格式」錯誤訊息，且不會觸發登入請求

---

## [x] 【表單驗證】密碼長度不足時顯示錯誤訊息
**範例輸入**：輸入有效 Email，在密碼輸入框輸入 `1234567`，並點擊登入按鈕  
**期待輸出**：畫面顯示「密碼必須至少 8 個字元」錯誤訊息，且不會觸發登入請求

---

## [x] 【表單驗證】密碼未包含英數混合時顯示錯誤訊息
**範例輸入**：輸入有效 Email，在密碼輸入框輸入 `12345678` 或 `abcdefgh`，並點擊登入按鈕  
**期待輸出**：畫面顯示「密碼必須包含英文字母和數字」錯誤訊息，且不會觸發登入請求

---

## [x] 【前端元素】非同步登入過程中的 Loading 狀態
**範例輸入**：輸入有效 Email 及密碼，點擊登入按鈕且 API 尚未回應時  
**期待輸出**：登入按鈕應變成 disabled 狀態，並顯示「登入中...」及載入動畫，且所有輸入框皆被禁用

---

## [x] 【Mock API】登入成功後導向至儀表板
**範例輸入**：輸入有效 Email 及正確密碼，並點擊登入按鈕（API 回傳成功）  
**期待輸出**：成功呼叫 context 的 `login` 方法，隨後畫面導向至 `/dashboard`

---

## [x] 【Mock API】登入失敗時顯示 API 錯誤訊息
**範例輸入**：輸入有效 Email 及密碼，點擊登入按鈕（API 回傳失敗）  
**期待輸出**：畫面上方的錯誤區塊顯示 API 回傳的錯誤訊息（或預設的「登入失敗，請稍後再試」）

---

## [x] 【驗證權限】已登入狀態下訪問登入頁應立即導向
**範例輸入**：在 API 的 `isAuthenticated` 為 `true` 狀態下訪問 `/login`  
**期待輸出**：無須任何操作，自動導向至 `/dashboard`

---

## [x] 【邏輯驗證】收到登入過期訊息時顯示提示並清除
**範例輸入**：從 `useAuth` 取得的 `authExpiredMessage` 包含內容（例如登入已過期）  
**期待輸出**：進入頁面時，畫面正確顯示該過期提示訊息，且有呼叫 `clearAuthExpiredMessage` 清除該狀態
